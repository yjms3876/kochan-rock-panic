# こーちゃんのロックパニック！

空から落ちてくる岩を避けながら、パンチで岩を破壊するレトロゲーム風のブラウザゲームです。

## ゲームを遊ぶ

[こーちゃんのロックパニック！をブラウザで遊ぶ](https://yjms3876.github.io/kochan-rock-panic/)

パソコンのブラウザで遊べます。音声は「ゲームスタート」ボタンを押した後に再生されます。

## 操作方法

| キー | 操作 |
| --- | --- |
| `←` | 左へ移動 |
| `→` | 右へ移動 |
| `Space` | 1回押すごとに頭上へ1発パンチ（攻撃間隔は約0.25秒） |
| `Space` 長押し | 稲妻アイテムの効果中・フィーバー中だけ連続パンチ |
| `Enter` | ゲームオーバー後に再スタート |

## ゲームのルール

- 主人公の「こーちゃん」を左右に動かして、空から落ちてくる岩を避けます。
- 通常の岩は、頭上へのパンチで破壊できます。
- 岩を破壊すると75ポイントがスコアへ加算され、岩の位置に「+75」と表示されます。
- 銀色の鉄岩は、通常パンチで上へ弾けます。拳に当たっただけではダメージを受けませんが、体に当たるとダメージを受けます。
- こーちゃんの体力は150です。画面左上の緑色のゲージで残り体力を確認できます。
- 岩に当たると、小岩は20、中岩は50、大岩は100、鉄岩は150の体力を失います。
- 体力が0になるとゲームオーバーです。
- ダメージを受けた後は約1秒間点滅し、その間は次の岩によるダメージを受けません。
- 時間が進むにつれて、岩の速さや数が増えて難しくなります。
- ハイスコアはブラウザに保存されます。

## コンボとフィーバー

- 岩を壊してから2秒以内に次を壊すとコンボが続きます。5連続から破壊得点が1.5倍、10連続から2倍になります。
- コンボが途切れても減点はありません。生存中は毎秒10ポイント加算されます。
- 通常時に岩を12個壊すと、自動で6秒間のフィーバーに入ります。押し返しただけではゲージは増えません。
- フィーバー中はアイテムなしでも長押しで連続パンチができ、パンチが大きくなり、鉄岩も一撃で壊せます。無敵になり、ヘルメットとグローブの回数は消費しません。
- フィーバー中は次回のゲージをためず、終了後に0からため直します。残り2秒になると枠と表示が点滅します。
- 終了画面には今回の最高コンボも表示されます。

## 強化アイテム

空から落ちてきたアイテムに触れると、自動で取得して装着できます。

### 稲妻（連打アイテム）

- 黄色い稲妻のアイテムを取ると、5秒間だけ `Space` 長押しで約0.25秒間隔の連続パンチができます。
- 通常時は、押し続けても最初の1発だけです。次のパンチは一度キーを離してから押します。
- 残り時間はこーちゃんの頭上のゲージに表示され、残り1秒で点滅します。攻撃していない間も時間は減ります。
- 効果中に再取得すると残り時間が5秒に戻ります。時間は加算されません。
- フィーバー中は残り時間の減少を止め、終了後に再開します。フィーバー中に取った場合も5秒分を保持します。
- ヘルメット・グローブ・稲妻は同じ確率で出現します。出現間隔は従来どおり、初回10〜15秒、その後15〜25秒です。

### ヘルメット

- 装着中は、通常岩または鉄岩によるダメージを1回だけ完全に防ぎます。
- 岩を防ぐとヘルメットは壊れてなくなります。
- ヘルメットは複数個ためることができません。

### パンチンググローブ

- 装着中は、鉄岩を上向きパンチで粉砕できます。
- 鉄岩を1個粉砕すると100ポイントが加算されます。
- 鉄岩を3個粉砕するとグローブはなくなります。
- 空振りや通常岩の破壊では使用回数を消費しません。

### 回復薬

- 緑色の印がある鉄岩をパンチンググローブ、またはフィーバー中のパンチで破壊すると、回復薬が落ちます。
- 回復薬に触れると、体力が最大50回復します。
- 体力は最大150まで回復し、満タンのときは回復薬を取得しません。
- 地面に落ちた回復薬は、一定時間取得されないと消えます。

## 音

ゲーム中はレトロ風のBGMが流れます。また、次の場面で効果音が鳴ります。

- パンチしたとき
- 通常の岩を破壊したとき
- 通常の岩に当たったとき
- 鉄岩に当たったときの金属音
- 回復薬を取得したとき

## ローカルで遊ぶ方法

このリポジトリをダウンロードまたはクローンし、`index.html` をブラウザで開きます。

ローカルサーバーを使う場合は、このフォルダで次のコマンドを実行します。

```bash
python3 -m http.server 8000
```

その後、ブラウザで次のURLを開きます。

```text
http://localhost:8000/
```
