# こーちゃんのロックパニック！

空から落ちてくる岩を避けながら、パンチで岩を破壊するレトロゲーム風のブラウザゲームです。

## ゲームを遊ぶ

[こーちゃんのロックパニック！をブラウザで遊ぶ](https://yjms3876.github.io/kochan-rock-panic/)

パソコンのブラウザで遊べます。音声は「ゲームスタート」ボタンを押した後に再生されます。

## 操作方法

| キー | 操作 |
| --- | --- |
| `←` | 左へ移動 |
| `→` | 右へ移動 |
| `Space` | 頭上へパンチ |
| `Shift` | 近くのアイテムを取得 |
| `Enter` | ゲームオーバー後に再スタート |

## ゲームのルール

- 主人公の「こーちゃん」を左右に動かして、空から落ちてくる岩を避けます。
- 通常の岩は、頭上へのパンチで破壊できます。
- 岩を破壊すると75ポイントがスコアへ加算され、岩の位置に「+75」と表示されます。
- 銀色の鉄岩は、通常のパンチでは壊せません。
- 通常の岩や鉄岩がこーちゃんに当たるとゲームオーバーです。
- 時間が進むにつれて、岩の速さや数が増えて難しくなります。
- ハイスコアはブラウザに保存されます。

## 強化アイテム

空から落ちてきたアイテムの近くで `Shift` キーを押すと、アイテムを取得して装着できます。

### ヘルメット

- 装着中は、通常岩または鉄岩への衝突を1回だけ防ぎます。
- 岩を防ぐとヘルメットは壊れてなくなります。
- ヘルメットは複数個ためることができません。

### パンチンググローブ

- 装着中は、鉄岩を上向きパンチで粉砕できます。
- 鉄岩を1個粉砕すると100ポイントが加算されます。
- 鉄岩を3個粉砕するとグローブはなくなります。
- 空振りや通常岩の破壊では使用回数を消費しません。

## 音

ゲーム中はレトロ風のBGMが流れます。また、次の場面で効果音が鳴ります。

- パンチしたとき
- 通常の岩を破壊したとき
- 通常の岩に当たったとき
- 鉄岩に当たったときの金属音

## ローカルで遊ぶ方法

このリポジトリをダウンロードまたはクローンし、`index.html` をブラウザで開きます。

ローカルサーバーを使う場合は、このフォルダで次のコマンドを実行します。

```bash
python3 -m http.server 8000
```

その後、ブラウザで次のURLを開きます。

```text
http://localhost:8000/
```
